2 · Box Model

content · padding · border · margin

box-sizing: content-box (default) vs box-sizing: border-box

content-box

width: 200px adds OUTSIDE padding+border.
Total rendered width = 200 + 40 + 4 = 244px

border-box

width: 200px INCLUDES padding+border.
Total rendered width = 200px exactly.

Margin collapse

Adjacent vertical margins collapse to the larger of the two. They do not add up.

margin-bottom: 30px
margin-top: 20px — gap above is 30px, not 50px.

outline vs border

outline does not affect layout (no space reserved). border is part of the box model.
