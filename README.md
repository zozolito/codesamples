## 🇬🇧 English

### What is this?

This is a free, community-oriented repository of code samples, learning resources, tricks, and tips.

It exists because of a simple observation: **we are living through a vibe coding epidemic.**

AI tools are wonderful. They accelerate development, lower the barrier to entry, and help experienced developers ship faster. But somewhere along the way, a new generation of "developers" emerged — people who copy-paste from ChatGPT, deploy to production, and have no idea what their code actually does. No idea what SQL injection is. No idea why `eval()` is dangerous. No idea that their password hashing function is from a Stack Overflow answer written in 2009.

**This is not a judgment. This is a wake-up call.**

If you are a beginner, welcome. This repo is for you. You will find code that is explained, dissected, and contextualised. Code that teaches you *why*, not just *what*.

If you are an experienced developer, contribute. Share the thing that took you three days to debug. Share the footgun you finally understand. Help someone else not repeat your mistakes.

### Why FORTRAN?

FORTRAN (Formula Translation) was born in 1957. It is older than most of your parents. It powered the Apollo missions, the first weather simulations, the early days of scientific computing.

Understanding FORTRAN is not about becoming a FORTRAN developer. It is about understanding that **every abstraction you use today was built on top of something else**. Knowing the roots makes you a better programmer. Full stop.
